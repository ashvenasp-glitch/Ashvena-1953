## Getting a .cdr
These are **CMX** files (Corel Presentation Exchange), Corel's own vector format. Every CorelDRAW version opens them natively. To get a `.cdr`:

1. CorelDRAW → **File → Open** → pick the `.cmx` file.
2. **File → Save As** → *CDR - CorelDRAW* → choose your CorelDRAW version.

The artwork is centred on the page. Set the page size to the artboard size from the table above (Layout → Page Size) if you need it.

No open-source tool can write a native `.cdr` file from scratch, so CMX is the exact, lossless way to hand vector art to CorelDRAW.
