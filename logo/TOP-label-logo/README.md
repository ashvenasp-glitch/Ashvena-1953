# TOP label logo: CorelDRAW file

`TOP_label_logo_3in-2in-1in.cmx` is one file with 3 pages, converted from `TOP_lable_logo_top.ai`. All artwork is vector and keeps the original CMYK colours.

![Preview](preview.png)

| Page | Layer name | Circle size (measured in the file) |
|---|---|---|
| 1 | Large 3in | 3.000 × 3.000 in (76.2 mm) |
| 2 | Medium 2in | 2.000 × 2.000 in (50.8 mm) |
| 3 | Small 1in | 1.000 × 1.000 in (25.4 mm) |

Each page holds a maroon mark on a light-blue circle. Sizes were checked by reading the saved file back. The largest deviation is 0.003 pt (0.001 mm).

**Colours (CMYK)**
- TOP Light Blue: C19 M0 Y4 K0
- TOP Maroon: C27 M100 Y86 K26

## Getting a .cdr
CMX (Corel Presentation Exchange) is Corel's own vector format, and CorelDRAW opens it natively.

1. CorelDRAW → **File → Open** → `TOP_label_logo_3in-2in-1in.cmx`.
2. **File → Save As** → *CDR - CorelDRAW*.

CMX stores layer names but not page names. To name the pages, right-click each page tab → *Rename Page* (Large 3in / Medium 2in / Small 1in). If you want the page itself to match the logo, set its size in Layout → Page Size. The logo is centred on the page.
